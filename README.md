# WoW Forever Intel

A personal, non-commercial AI-powered knowledge assistant dedicated to World of Warcraft: Forever.

Project objectives

Comprehensive, searchable game knowledge.

Version-aware information and source verification.

On-demand research into new content and gameplay changes.

Guidance covering mechanics, quests, items, professions, economy, lore, and player communities.

Development status

A working local prototype has been developed using Python, SQLite, and OpenCode. Structured data ingestion and knowledge coverage are currently being expanded.

Data attribution

The project intends to integrate data from ForeverDB.net upon API access approval. Data retrieved from ForeverDB will retain source attribution and comply with its API requirements.

This is an independent fan project and is not affiliated with Blizzard Entertainment.
